# Rapport — [TD3]

## Points clés

### 1. [Modèle événement → état → rendu]

L'évenemment est l'action faite sur la page (exemple : clic sur l'icone coeur d'un article),
l'état correspond au changement qui se produit dans le programme (exemple : coeurVide → coeurPlein),
et le rendu est ce qu'il se passe visuellement pour l'utilisateur (exemple : le coeur devient coloré pour signifier qu'il a été validé).

### 2. [classList.toggle ; la passerelle entre JS et CSS]

Avec le CSS, on habille les classes visuellement (on change les tailles, les couleurs, etc).
Avec JavaScript, on ajoute l'interactivité ; on active ou non les classes et leurs CSS selon les actions de l'utilisateurs.
classList.toggle est une passerelle entre JS et CSS car elle ajoute la classe si elle est absente, et la retire si elle est présente, c'est une dépendance mutuelle entre le JavaScript et le CSS.
