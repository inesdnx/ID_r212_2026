# Rapport — [TD2]

## Points clés

### 1. Margin

Margin sert à rajouter une marge, pour aérer les éléments sur la page.

### 2. .container

Container est une classe utile pour faire des blocs.

### 3. padding

Le padding est ce qui détermine à l'espace à l'interieur de l'élément (contrairement au margin qui est à l'extérieur de l'élément).
